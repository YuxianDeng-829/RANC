# Benchmark datasets

Each MAT file contains `X`, a matrix with one sample per row and one feature per column, and `Y`, a column vector of class labels. Dataset names follow Table 2 of the RANC article. Use the file stem to select a dataset in `demo_RANC_datasets`.

| Name in the paper | MAT file | Samples | Features | Classes |
| --- | --- | ---: | ---: | ---: |
| Seeds | `Seeds.mat` | 210 | 7 | 3 |
| Jaffe50 | `jaffe50_uni.mat` | 213 | 1024 | 10 |
| ORL64 | `ORL64.mat` | 400 | 4096 | 40 |
| Digits | `dig1-10_uni.mat` | 1797 | 64 | 10 |
| MSRA25 | `MSRA25.mat` | 1799 | 256 | 12 |
| Coil20 | `Coil20.mat` | 1440 | 1024 | 20 |
| Palm25 | `PalmData25.mat` | 2000 | 256 | 100 |
| Pendigits | `Pendigits.mat` | 10992 | 16 | 10 |

For redistribution terms, consult the original dataset providers.
